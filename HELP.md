# Simple Line Editor - Help

## 1. Insert Line

Used to add a new line at a specific line number.

### Usage
Choose option 1.

Example:
1
Enter line number: 2
Enter the text: Hello World

---

## 2. Delete Line

Used to remove a line from the document.

### Usage
Choose option 2.

Example:
2
Enter line number: 1

---

## 3. Display Document

Displays all lines with their line numbers.

### Usage
Choose option 3.

Example:
3

---

## 4. Exit

Closes the line editor.

### Usage
Choose option 4.

Example:
4
