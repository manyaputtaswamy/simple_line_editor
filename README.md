## Project Description

A simple command-line line editor developed in C.

The editor stores text lines in memory and allows the user to insert,
delete and display lines.

## Features Implemented

- Insert a line
- Delete a line
- Display the document

## Data Structure

The project uses an array of strings to store the document lines.

gcc main.c -o simple_line_editor
